# Changelog

## 1.1.0

- Added item upgrade track and level next to the item level.
- Added automatic filtering for refundable items.
- Added a learned exclusion list for items rejected by the game.
- Added a persistent history of the 50 most recent successful disenchants.

## 1.0.0

- Initial public release.
- Added compact disenchanting queue.
- Added rarity filters and Select All.
- Added adjustable, persistent interface scaling.
- Added English and French localization.
- Added secure one-click disenchant action.
- Added automatic bag refresh and combat protection.
